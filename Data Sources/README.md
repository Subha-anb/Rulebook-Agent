# Data Sources

The document pack the Rulebook Agent answers from. All documents are fictional samples or
simplified for testing, and they are not legal advice.

| Doc | Document | What it holds | Revised |
| --- | --- | --- | --- |
| 1 | California RFP | Requirements, dates, deliverables, evaluation criteria, Addendum 1 | Annually |
| 2 | Kansas UX assets | Reusable assets, IP status, research findings, gaps | Quarterly |
| 3 | Compliance rules | Rule catalog and the checkpoint for each rule | Quarterly |
| 4 | Skills and rates | Staff inventory, rate card, staffing plan | Quarterly |
| 5 | Contract library | Clause playbook, fallbacks, approvers, contract outline | Quarterly |
| 6 | Past bids | Bid register, estimate benchmarks, lessons learned | Annually |

## Versions

Files with no version in their name are version 1.0. A file ending in `- 1.1` replaces the
file of the same name without a version.

The `Rulebook Agent Document Register.xlsx` file one folder up decides which versions are
current. The agent loads only the files marked Current there and ignores everything else in
this folder, including this README and the copy of the register kept here.

## Adding a new version

1. Add the new file here, with its version in the name.
2. In the main register, add its row as Current and mark the old row Superseded.
3. Restart the app.

Close these files in Word before starting the app, because it can't read a file that's open.
